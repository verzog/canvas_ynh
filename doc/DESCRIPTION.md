Canvas LMS is the open-source Learning Management System developed by Instructure. It provides course management, assignments, quizzes, grading (Gradebook), discussions, a calendar, and integrations (LTI) for schools, universities and training organisations.

This package installs the open-source (AGPLv3) edition of Canvas from Instructure's source, building its Ruby runtime and compiling its frontend assets on the server.

**Heads up — Canvas is resource-heavy.** It is a large Ruby on Rails application. Installation builds Ruby and runs a webpack asset compile, which needs roughly 4 GB of RAM to build and around 2 GB to run comfortably. It is not suitable for small/low-memory VPS instances.
